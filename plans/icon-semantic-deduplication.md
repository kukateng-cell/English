# 全站圖標語義去重及入口重設計計劃

> 狀態：已完成（local verification）
>
> 範圍：學生、教師、管理員及共用頁面的可見圖標語義；不改學習流程、資料、權限或 API。

## 背景

現有圖標已大致統一到共用 `Icon`／`RewardIcon`，但部分不同功能仍共用同一圖形。例如單元闖關與學習入口都使用閃光圖標，排行榜與統計都使用柱狀圖，成就與學習入口亦使用相同圖形。圖形風格雖然一致，語義卻不夠清楚，學生難以從入口快速分辨功能。

## 目標

- 建立「功能語義 → 唯一圖標」對照表，避免不同功能入口重複使用同一個主圖標。
- 保留共用導覽／操作圖標（返回、搜尋、關閉、確認、鎖定、發音等）的一致性；只替換語義不同的功能圖標。
- 以 `Icon` 表達一般功能，以 `RewardIcon` 表達排行榜、成就及獎勵，維持 EMM Style 02 線條、尺寸及顏色規則。
- 讓 desktop、tablet、mobile 使用同一語義對照，並保留文字、鍵盤及螢幕閱讀器名稱。

## Canonical 語義對照

| 功能 | 圖標 | 原因 |
|---|---|---|
| 學習入口 | `spark` | 泛指開始學習／探索 |
| 單元闖關 | `route` | 表達按單元逐步前進 |
| 統計／詳細統計 | `bar-chart` | 數據及進度分析 |
| 排行榜 | `RewardIcon trophy` | 名次及競賽 |
| 成就 | `RewardIcon star` | 解鎖徽章及達成目標 |
| 學生名冊／班級名單 | `clipboard` | 名冊及可檢查的清單 |
| 單詞庫／詞表 | `book` | 詞彙內容 |
| 客觀測驗 | `target` | 作答目標及測驗 |
| 練習／複習記錄 | `repeat` | 表示同一詞的重複練習次數，不與重新載入混用 |
| 複製 | `copy` | 表示把內容複製到剪貼簿 |
| 圖片 | `image` | 表示圖片內容或圖片缺失狀態 |

返回、箭頭、搜尋、資訊、錯誤、重新載入、鎖定、眼睛、音量、主題及登出等操作圖標屬共用工具語義，維持重複使用。

## 非目標及安全邊界

- 不改 API、資料庫、權限、學習證據、SM-2、統計數值或匯出資料。
- 不修改 `RewardIcon` 的排行榜／成就資料語義，只調整使用位置及圖形分類。
- 不刪除共用工具圖標；如同一工具語義在多個頁面出現，保留一致性。

- 學生首頁四個功能入口可一眼分辨：單元闖關、統計、排行榜、成就各有專用圖標。

- 所有修改保留文字、aria 名稱、鍵盤操作及明暗／簡繁主題支援。
- 實際測試及尚未執行的瀏覽器矩陣已記錄在本計劃。
