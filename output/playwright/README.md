# UI migration visual evidence

These artifacts are the reviewable visual evidence for `plans/ui-design-system-migration.md`.
They are generated from the local production build and are intentionally kept under
`output/playwright/`; transient Playwright CLI snapshots are ignored by `.gitignore`.

- Prototype source: `/Users/hangwong/Documents/Design/emm_style_01/`
- Prototype reference captures: `prototype-reference/reference/`
- Foundation fixture captures: `phase1-fixture/`
- Student final captures and comparison notes: `phase6/`
- Teacher/admin workspace captures: `phase5/`

Reference and implementation captures use the same named viewport files wherever a
prototype screen exists: `390x844`, `820x1180`, and `1440x900`. The authenticated
captures use seeded real data only; no prototype sample identity or fixed prototype
statistics are used by production routes.
